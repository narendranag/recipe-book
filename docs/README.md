# recipe-book documentation

recipe-book is Nag Family Recipes, a NYT Cooking–style recipe site for the family at [recipes.nag.family](https://recipes.nag.family). It turns a YouTube playlist and an Apple Notes folder into static recipe pages, with search and category filtering, and needs no login, database or runtime configuration.

**Status:** built and in production on Cloudflare Workers since 2026-10-21.

## Terms used throughout

| Term    | Meaning                                                                                                   |
| ------- | --------------------------------------------------------------------------------------------------------- |
| Recipe  | One `.mdx` file under `content/recipes/`; all its data is YAML front matter                               |
| Slug    | A recipe's URL name, `/recipe/<slug>`; unique across every source folder                                  |
| Source  | Where a recipe came from: `youtube`, `notes` or `manual`, and the folder it lives in                      |
| Rewrite | The pass by `scripts/rewrite_recipes.py` in which Claude cleans a new recipe's title, ingredients and steps |
| Worker  | The Cloudflare Worker `recipe-book` that serves the site, built with OpenNext                             |
